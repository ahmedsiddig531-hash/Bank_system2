 # 🏦 Bank Management System

A console-based **Bank Management System** developed in C++ to simulate basic banking and ATM operations.

The project focuses on practicing **Object-Oriented Programming concepts, file handling, functions, enums, vectors, user permissions, and menu-driven systems** in C++.

## 🚀 Features

### 👤 Client Management
- Add new clients
- Update client information
- Delete clients
- Find clients by account number
- List all clients
- Check client balance

### 💳 Transactions
- Deposit money
- Withdraw money
- Transfer money
- View transaction information
- Update account balances

### 🏧 ATM Operations
- Client login using account number and PIN
- Check balance
- Normal withdrawal
- Quick withdrawal
- Deposit money
- Logout

### 🔐 User Management
- Add users
- Delete users
- Update users
- Find users
- List users
- User permissions

## 🛠️ Technologies

- **C++**
- File Handling (`fstream`)
- STL `vector`
- Functions
- Structures
- Enums
- Input Validation
- Console Menus
- Text File Storage
